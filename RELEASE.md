## Omni — latest build

Omni is a multi-surface application: a desktop app (macOS bundle),
browser extensions (v2 and v3), and companion CLI tooling — all built
from one pnpm/Turborepo workspace.

### Download

- **macOS**: `Omni.app.zip`
- **Browser extensions**: `omni-v2.zip`, `omni-v3.zip`
- **CLI**: platform binaries — see assets
