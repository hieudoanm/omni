# AGENTS.md

- Technical reference for working in the Omni monorepo.
- The README explains what the project is.
- This file is the index; each package has its own conventions.

## Read this first

- **Eight packages, one monorepo** — six native apps, a static web page, and editor extensions under `packages/extensions/`; no shared UI, no Electron. `packages/cli` is the shipped Rust CLI; `packages/cli.go` is the legacy Go implementation kept as the port reference (no longer built by CI or released).
- `pnpm` + Turborepo for Node workspaces (browser + VS Code extensions, web); Gradle for Android; Xcode for iOS.
- Root scripts delegate to per-package Makefiles: `format`, `lint`, `test`, `build`.
- CI uses per-platform runners: Ubuntu (Android, CLI, Browser), macOS (macOS). iOS builds locally via `xcodebuild` (not yet in CI).
- Rolling `latest` release on every push to `master`.

## Root Commands

```bash
pnpm install          # installs all workspace deps (browser, vscode, web)
pnpm format           # turbo run format (all packages)
pnpm lint             # turbo run lint (all packages)
pnpm typecheck        # turbo run typecheck (browser, web)
pnpm test             # turbo run test (all packages)
pnpm build            # turbo run build (all packages)
```

## Per-Package Conventions

### Android (`packages/mobile/android`)

- **Kotlin 2.4**, Compose BOM 2026.09, Gradle 9.8 (wrapper).
- **Hilt** for DI — `@HiltAndroidApp` on `OmniApp`, `@AndroidEntryPoint` on Activities, `@HiltViewModel` on ViewModels.
- **Compose** — Material3, `remember`/`derivedStateOf`, `LaunchedEffect` for side effects.
- **Room** — DAOs return `Flow`; `@Entity` with `@PrimaryKey(autoGenerate = true)`.
- **DataStore Preferences** — `Preferences.DataStore<Preferences>`, typed keys via `stringPreferencesKey()`.
- **NFC** — `NfcAdapter.enableForegroundDispatch()` with `ACTION_TAG_DISCOVERED` (suppressed deprecation), `Ndef`/`IsoDep` for reading.
- **Tests** — Robolectric 4.17, JUnit 4, Turbine for Flow testing, MockK for mocks.
- **Format** — Spotless + ktlint 0.50.0 (configured in `app/build.gradle.kts`).
- **Lint** — Android Lint (`:app:lintDebug`), zero warnings.
- **No `local.properties`** — `ANDROID_HOME` from env / CI.

### iOS (`packages/mobile/ios`)

- **Swift 6 / SwiftUI**, Xcode project (`Omni.xcodeproj` generated by `xcodegen` from `project.yml` — edit the yml, not the pbxproj).
- **Core NFC** — `NFCTagReaderSession` one-shot read/write; `NfcService` is a plain `@unchecked Sendable` class because CoreNFC callbacks arrive on the session's serial queue.
- **SwiftData** — tag scan history; **UserDefaults** — NFC settings (`SettingsStore`).
- **Scope vs Android** — Omni hub + NFC Toolkit (read/write/history). **No Focus Blocker** (no iOS equivalent of AccessibilityService app blocking) and **no HCE** (iOS cannot emulate NFC cards to other readers).
- **Tests** — Swift Testing (`OmniTests/`) covering `NdefCodec`, `NdefRecord` Codable, `SettingsStore`.
- **Build** — `make build` / `make test` wrap `xcodebuild` (simulator destination `iPhone 16`, override `DESTINATION=`). Requires macOS + Xcode; real NFC scans need a physical device.
- **Format** — `swiftformat Omni OmniTests` (`make format` / `make format-check`).

### macOS (`packages/desktop/macos`)

- **Swift**, SwiftUI, native Xcode project (`Omni.xcodeproj` generated by `xcodegen` from `project.yml` — edit the yml, not the pbxproj).
- **Architecture** — `OmniCore` framework target (models, services, providers), `Omni` app target (view models, services, views), `OmniTests` bundle; sources live in `OmniCore/`, `Omni/`, `OmniTests/`.
- **Swift Testing** — `@Suite`, `@Test`, `#expect`, 219 tests / 36 suites.
- **Design tokens** — `Omni/Views/Shared/DesignSystem/`: color, spacing, typography, elevation, radius, animation.
- **Reduced motion** — `@Environment(\.accessibilityReduceMotion)` respected.
- **Format** — `swiftformat Omni OmniCore OmniTests` (`make format` / `make format-check`).
- **Lint** — `xcodebuild build` (`make lint`, Debug config).
- **App bundle** — `make app` stages `build/Omni.app` (Xcode-signed, ad-hoc) with `Info.plist`, `Assets.xcassets` AppIcon, `Omni.entitlements`.
- **DMG** — `make dmg` creates distributable via `hdiutil`.

### CLI — Rust port (`packages/cli`)

- **Rust** (stable, edition 2021), clap derive for the command tree, single `omni` binary.
- **Complete port** of `packages/cli.go` — all 33 modules done; MCP server exposes 437 tools. This is the binary CI builds and releases ship.
- **Layout** — `src/cli.rs` (root Parser + dispatch), `src/<module>.rs` or `src/<module>/` mirroring `cli.go/src/cmd/`, shared libs in `src/*.rs`.
- **`--json` (`-j`)** — `global` arg on each module root, threaded to leaf `run()` fns.
- **History** — `src/history.rs` mirrors the Go `libs/history` (`~/.omni/history.jsonl`, same exclusions).
- **Version** — `build.rs` sets `OMNI_VERSION` (`<date>-<sha>` or env override), same format as the Go ldflags injection.
- **Commands** — same Makefile interface as the Go package (`format`/`lint`/`test`/`build`/`build-all`/`install`/`clean`); `build-all` cross-compiles via `rustup target` (no Zig needed).

### CLI — Go reference (`packages/cli.go`)

- **Go 1.27** (go.mod `1.27.2`), Cobra for commands, Bubble Tea for TUI modules.
- **Module path** — `github.com/hieudoanm/omni/packages/cli.go`.
- **33 modules** under `src/cmd/` — each has `cmd.go`, optional `service.go`, `*_test.go`.
- **MCP server** — `src/cmd/mcp/serve.go` exposes all modules as MCP tools over stdio.
- **Vendored API** — Gemini client at `src/libs/api/gemini.google.com/` (copied from old `github.com/hieudoanm/api`).
- **Pinned deps** — `pdfcpu v0.15.0` (v0.16.x breaks `pdf` command).
- **Cross-compile** — `make build-all` uses Zig CC for non-native targets (`linux/amd64`, `linux/arm64`, `darwin/amd64`, `darwin/arm64`); darwin binaries are `CGO_ENABLED=0` stubs (no Apple SDK headers under zig), so `make build-darwin` on macOS produces the real cgo-enabled darwin binaries used by the release.
- **Version** — `-ldflags="-X github.com/hieudoanm/omni/packages/cli.go/src/cmd/version.V=date-sha"`.
- **Format** — `go fmt ./...`
- **Lint** — `go vet ./...`
- **Test** — `go test ./...` (479 packages).
- **Install scripts** — `packages/cli.go/scripts/install.sh` installs release artifacts (asset names unchanged); `scripts/install-local.sh --cli` builds `packages/cli` from source.

### Browser Extension (`packages/extensions/browser`)

- **TypeScript 6.0**, Manifest V3, React 19, Tailwind 4.
- **Webpack 5** — separate configs for background, content, popup, options.
- **ESLint** — `@typescript-eslint`, `eslint-plugin-react`, `eslint-plugin-tailwindcss`.
- **Prettier** — Tailwind plugin for class sorting.
- **Vitest** — unit tests, jsdom environment.
- **Structure** — `apps/` (background, content, popup, options), `libs/` (shared), `components/` (React).
- **Checks** — `pnpm lint` mutates (`--fix`); use `pnpm lint:check` / `pnpm format:check` in CI. `pnpm typecheck` runs `tsc --noEmit`.

### VS Code Extension (`packages/extensions/vscode`)

- **Nothing-inspired dark theme** — single theme JSON at `themes/nothing.json`, icons in `icons/`.
- **`@omni/vscode`** — VS Code extension manifest in `package.json` (`contributes.themes`); theme-only, no `main`/activation code.
- **Package** — `pnpm package` runs `vsce package` → `build/nothing-vscode-theme-0.0.1.vsix`.
- **Format** — `prettier --write` / `format:check`; no lint/typecheck/test scripts.

### Web (`packages/web`)

- **Next.js 16** App Router, static export (`output: "export"` → `out/`), Tailwind 4, Turbopack, React 19.
- **Deploy** — GitHub Pages via `actions/upload-pages-artifact` + `deploy-pages`; `basePath` is `/omni` in production.
- **Typecheck** — `pnpm typecheck` runs `next typegen && tsc --noEmit` (`next-env.d.ts` and `.next/types` are gitignored and regenerated).
- **Format** — `prettier --write` / `format:check`; **Lint** — `eslint` (flat config `eslint.config.mjs`).

## Design Baseline

`packages/web` is the UI baseline for every package — a dark sci-fi HUD theme.

- **Palette** — bg `#020813`, surface `#0a1424` / `#0f1e33`, border `#14304a`,
  accent `#16dfff`, accent-2 `#8afaff`, accent-dim `#008cff`, text `#ededed`,
  muted `#7d93ad`. Tokens live in `packages/web/src/app/globals.css`.
- **Typography** — Orbitron for display/title/label roles, DM Mono for body.
  Fonts are bundled locally (OFL): `packages/extensions/browser/public/fonts/*.woff2`,
  `packages/mobile/android/app/src/main/res/font/{orbitron,dmmono_*}.ttf`;
  iOS copies at `packages/mobile/ios/Omni/Resources/Fonts/`.
- **Per package** — browser: `public/popup.css` + `public/index.html` +
  injected wall styles in `src/lib/block.ts`; Android: `*/ui/theme/{Color,Theme}.kt`
  (identical HUD palette in omni/block/nfc, dark-first with light variant);
  CLI: ANSI-256 approximations in `src/libs/theme/theme.go`; macOS:
  `Palette.accent`/`onAccent` dynamic colors in
  `Omni/Views/Shared/DesignSystem/Palette.swift`; iOS:
  `Omni/Theme/{Palette,Typography,OmniTheme}.swift`.

## Non-Negotiables

- **Per-package Makefiles** — root `pnpm` scripts delegate; never call Gradle/Swift/Go directly from root.
- **No shared UI code** — each platform owns its view layer.
- **Vendored, not linked** — external code copied in (Gemini client), not replaced.
- **Rolling `latest` only** — no version tags; CI force-updates `latest` release.
- **Keep diffs minimal** — don't reformat unrelated files.
- **Build outputs gitignored** — `build/`, `.build/`, `bin/`, `coverage/`, `dist/`, `.gradle/`, `.kotlin/`.

## Adding a CLI Module

Go reference (`packages/cli.go`):

1. Create `src/cmd/<category>/<module>/cmd.go` with `cobra.Command`.
2. Add `service.go` for logic, `*_test.go` for tests.
3. Register in `src/cmd/root.go` `init()`.
4. Run `go mod tidy`, `go vet ./...`, `go test ./...`.

Rust port (`packages/cli`):

1. Create `src/<module>.rs` (or `src/<module>/` for modules with children) with a `clap::Args` struct + `run()`.
2. Register the variant in `src/cli.rs` `Command` enum + `dispatch()`.
3. Add `#[cfg(test)]` tests; run `cargo fmt`, `cargo clippy --all-targets -- -D warnings`, `cargo test`.

## Gotchas

- **Android** — `ANDROID_HOME` must be set; `local.properties` is gitignored.
- **macOS** — must run on macOS runner; `codesign` requires entitlements.
- **iOS** — must run on macOS with Xcode; Core NFC only works on physical devices (simulator builds but cannot scan).
- **CLI** — Rust cross-compile via `rustup target add` (Makefile handles it); `*-apple-darwin` targets link only on the macOS runner.
- **Browser** — `pnpm install` only at root; lockfile is the root `pnpm-lock.yaml`.
- **Turborepo** — `globalEnv` passes `ANDROID_HOME`, `ANDROID_SDK_ROOT`, `JAVA_HOME` to tasks.
