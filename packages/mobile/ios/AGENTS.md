# Omni (iOS)

_Swift + SwiftUI iOS app porting the Omni hub and NFC Toolkit from `packages/mobile/android`._

---

# Goal

Deliver a single iOS app, **Omni**, whose home screen lists the bundled
applications. The Android package ships two apps — **Focus Blocker** and
**NFC Toolkit**. iOS ports the hub and the NFC Toolkit; Focus Blocker is
omitted because iOS provides no third-party app accessibility/overlay API,
and Android-style HCE is impossible because iOS cannot emulate a card for
external readers.

One Xcode **application** target hosts the hub UI, the `OmniApp` entry point,
and the NFC feature tree.

# NFC

- `NfcService` wraps `NFCTagReaderSession` for **read** and **write** of
  NDEF messages; it is a plain `@unchecked Sendable` class — session state
  (continuations, pending mode) is confined to the session's serial queue.
- `NFCTag` / `any NFCNDEFTag` are non-Sendable; they cross into `@Sendable`
  completions through `SendableBox<T>`.
- `NdefCodec` is the pure parse/serialize layer (ported from Android's
  `NdefReader`/`NdefWriter`); it has no Core NFC dependency and is fully
  unit-tested.
- History is SwiftData (`TagHistoryItem`); settings are `UserDefaults` via
  `SettingsStore`.
- Entitlements declare `NDEF` + `TAG` reader formats; `Info.plist` carries
  `NFCReaderUsageDescription`.
- **Device-only** — `NFCTagReaderSession.readingAvailable` is false on the
  simulator; the app shows the "NFC unavailable" path there.

# Design System

HUD theme matching `packages/web` / Android: bg `#020813`, surfaces
`#0a1424`/`#0f1e33`, border `#14304a`, accent `#16dfff`, accent-2 `#8afaff`,
accent-dim `#008cff`, text `#ededed`, muted `#7d93ad`. Orbitron for
display/title/label roles, DM Mono for body/data — fonts bundled locally in
`Omni/Resources/Fonts/` (OFL).

# Build & Test

```bash
make build     # xcodebuild, iPhone 16 simulator by default
make test      # xcodebuild test (Swift Testing)
make app       # print the built Omni.app path
make format    # swiftformat Omni OmniTests
make clean     # rm -rf build
```

`DESTINATION` overrides the simulator target, e.g.
`make build DESTINATION="generic/platform=iOS"` for a device build.

# Testing

Swift Testing (`@Suite`, `@Test`, `#expect`) in `OmniTests/`:

- `NdefCodecTests` — NDEF parse/serialize round-trips
- `NdefRecordCodableTests` — model Codable
- `SettingsStoreTests` — UserDefaults-backed settings

Core NFC itself cannot be unit-tested; it requires a physical device.

# Repository Responsibilities

- `Omni/Hub/` — hub only; cards navigate to feature areas.
- `Omni/NFC/` — all NFC read/write/history/settings logic.
- `Omni/Theme/` — the only place palette/typography values live.
- No shared UI code with other packages — per-platform view layers.
