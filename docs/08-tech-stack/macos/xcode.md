# macOS Xcode Project — project.yml & xcodebuild

The app is a plain Xcode project: `Omni.xcodeproj` is generated by
[xcodegen](https://github.com/yonaskolb/XcodeGen) from `project.yml` (the
source of truth — edit that, then run `xcodegen generate`).

## Targets

| Target      | Type                  | Sources        | Product                        |
| ----------- | --------------------- | -------------- | ------------------------------ |
| `OmniCore`  | framework             | `OmniCore/`    | `OmniCore.framework`           |
| `Omni`      | application           | `Omni/`        | `Omni.app` (menu-bar agent)    |
| `OmniTests` | unit-test bundle      | `OmniTests/`   | `OmniTests.xctest`             |

- `Omni` links `OmniCore` and reads `Omni/Info.plist` +
  `Omni/Omni.entitlements` (`CODE_SIGN_ENTITLEMENTS`).
- `OmniTests` uses `@testable import OmniCore`.
- Deployment target macOS 13, `SWIFT_VERSION` 5.0, ad-hoc code signing
  (`CODE_SIGN_IDENTITY = "-"`).

## Key settings (`project.yml`)

```yaml
settings:
  base:
    MARKETING_VERSION: "0.0.1"
    CURRENT_PROJECT_VERSION: "1"
    SWIFT_VERSION: "5.0"
targets:
  Omni:
    settings:
      base:
        INFOPLIST_FILE: Omni/Info.plist
        CODE_SIGN_ENTITLEMENTS: Omni/Omni.entitlements
        ASSETCATALOG_COMPILER_APPICON_NAME: AppIcon
```

## Build commands

```bash
xcodegen generate                                        # regenerate Omni.xcodeproj
xcodebuild -project Omni.xcodeproj -scheme Omni \
  -destination 'platform=macOS' -derivedDataPath build/DerivedData build
xcodebuild -project Omni.xcodeproj -scheme Omni \
  -destination 'platform=macOS' -derivedDataPath build/DerivedData test

# or via the Makefile
make build   # Release build
make lint    # Debug build (compile check)
make test    # xcodebuild test
make app     # stage build/Omni.app
make dmg     # build/Omni-0.0.1.dmg
make clean
```

## App bundle & resources

- `Omni/Info.plist` — `LSUIElement` menu-bar agent; version/executable/bundle-id
  come from build settings (`$(MARKETING_VERSION)`, `$(EXECUTABLE_NAME)`,
  `$(PRODUCT_BUNDLE_IDENTIFIER)`).
- `Omni/Resources/Assets.xcassets/AppIcon.appiconset` — app icon slots
  (pre-rendered PNGs committed to the repo).
- `Omni/Omni.entitlements` — app sandbox disabled.
- `xcodebuild` signs ad-hoc; `make dmg` packages the staged `.app` with
  `hdiutil`.

## CI

`make format-check`, `make lint`, `make test`, `make build`, `make app`,
`make dmg` on `macos-latest`; artifacts `build/Omni.app.zip` +
`build/Omni-*.dmg` upload to the `latest` release.
