# Omni — UI/UX Design

## 1. Purpose

Defines the popup UI structure, tabs, controls, states, and behaviour matching the actual extension popup (`popup.html`/`css`).

The design must be:

- Clear and technical (toolbar utility).
- Accessible (WCAG 2.1 AA).
- Consistent across panes.
- Explicit about busy, error, success, and hidden states.
- Jarvis-inspired dark blue theme with cyan highlights.

Every subsystem document below is normative. Where a subsystem document and this index disagree, the subsystem document governs.
